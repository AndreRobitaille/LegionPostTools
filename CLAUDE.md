# Claude Guidance

@AGENTS.md

`AGENTS.md` is the shared source for project identity, product and design requirements,
authorization, verification, and release discipline. Read task-relevant nested guidance
as well; `docs/superpowers/AGENTS.md` explains how to interpret dated plans and specs.

Product thinking, design, documentation, and specifications are first-class deliverables
when requested. Follow the user's task rather than assuming every session ends in code.
Keep project rules in shared guidance so every agent receives them.
