# Reading Dated Designs

This directory name records the tooling used when these designs were written. It does
not require Superpowers, its startup hook, or its execution skills. Root `AGENTS.md`
governs collaboration, authorization, and verification.

Use these documents for design rationale and substantive product requirements. Planned
steps, commands, checklists, and old implementation-status statements are not standing
instructions or evidence of current behavior. Execute steps only when relevant to the
user's authorized task. Preserve historical content rather than mass-rewriting it.

Check current code/tests and the root documentation map for shipped behavior. Current
minutes lifecycle/approval docs, `docs/ROLES.md`, and `docs/DEPLOYMENT.md` supersede older
workflow, access, and release plans. The visual system spec remains design guidance,
subject to later feature-specific design decisions.
